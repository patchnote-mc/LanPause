=== CUSTOM PAYLOAD NETWORKING ===
Payload type is net.minecraft.network.protocol.common.custom.CustomPacketPayload:
  Type<T extends CustomPacketPayload>(Identifier id); interface method: Type<? extends CustomPacketPayload> type();
Register payload TYPES in COMMON init (runs on both sides):
  PayloadTypeRegistry.serverboundPlay().register(TYPE, CODEC)   // C2S  (RegistryFriendlyByteBuf)
  PayloadTypeRegistry.clientboundPlay().register(TYPE, CODEC)   // S2C
Receivers:
  ServerPlayNetworking.registerGlobalReceiver(TYPE, (payload, context) -> ...)  // context.player()/server()/responseSender()
  ClientPlayNetworking.registerGlobalReceiver(TYPE, (payload, context) -> ...)  // context.client()/player()  (client init)
Send:
  ClientPlayNetworking.send(payload)                 // C2S
  ServerPlayNetworking.send(serverPlayer, payload)   // S2C
Empty payload codec: StreamCodec.unit(new MyPayload()). String codec: ByteBufCodecs.STRING_UTF8; bool: ByteBufCodecs.BOOL.
  Codec generics: StreamCodec<? super RegistryFriendlyByteBuf, T> (a plain ByteBuf/FriendlyByteBuf codec .cast()s fine).
NOTE: no Fabric event for Dialog ServerboundCustomClickActionPacket -> use a Minecraft mixin (see dialog knowledge).
